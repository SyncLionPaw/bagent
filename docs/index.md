## 这是什么

**bagent** 是一门**连载中的中文课程**：用 **JavaScript / TypeScript** 带你做出大模型 Agent。

| 阶段 | 课次 | 内容 |
|------|------|------|
| 第一阶段 | 1–10 | 对话、工具、联网、网页 UI |
| 第二阶段 | 11–21 | API 字段、本地推理、SSE 与浏览器流式 |
| 第三阶段 | 22–38 | Agent Loop、事件、VS Code 插件、Thinking / 审批 / 钩子 |
| 第四部分 | 39+ | ACP、三种产品形态（阅读）；动手实现连载中 |
